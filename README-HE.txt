מכונת סאונד לכפילויות
======================
1. מעלים את התיקיה הזאת ל-Railway / Render / כל שרת קטן עם Docker.
2. במשתנים שמים:
   TELEGRAM_TOKEN = אותו טוקן של הבוט
   DUP_HELPER_SECRET = dup-audio-7f3k
3. מעתיקים את כתובת האתר שיוצאת (https://....)
4. בקובץ הבוט ממלאים:
   const DUP_HELPER_URL = 'https://....';
5. מעלים מחדש את worker.js

בלי שלב 4 הכפתור בפאנל יגיד שאין מכונה. זה בכוונה.
